# 🎭 Custom Mask Generator

> Un projet de création et de personnalisation de masques sur-mesure, de la conception 2D modulaire jusqu'à l'export 3D prêt pour l'impression.

---

## 🚀 À propos du projet

Ce projet a pour ambition de permettre aux utilisateurs de concevoir leur propre masque personnalisé en combinant différentes parties modulaires (bouche, yeux, cornes, etc.). L'objectif est de proposer une interface interactive pour composer un design unique, d'abord sous forme de version 2D, avant d'évoluer vers une modélisation 3D exportable pour l'impression 3D.

---

## ✨ Fonctionnalités prévues

* **Personnalisation modulaire :** Choix des éléments par zone (yeux, bouche, cornes, etc.).
* **Prévisualisation interactive :** Assemblage dynamique des choix de l'utilisateur.
* **Téléchargement / Export :** 
  * *Étape 1 :* Export de la version 2D.
  * *Étape 2 :* Export du modèle 3D (`.STL`) pour l'impression physique.
